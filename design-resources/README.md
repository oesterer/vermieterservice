# Vermieter Service Design Resources

This folder is the central working area for research, content inventories, sitemaps, and planning material for the redesign of **vermieterservice.ch**.

All design documentation is written in English because communication between the property owner and web designer will take place in English. The future public website will be available in both German and English.
